# Novora Verify 4.18.5

- Schließungsanfragen von Ticket-Erstellern verwenden jetzt dieselbe Ticket-Sperre wie Teamaktionen. Gleichzeitig eintreffende Anfragen lösen höchstens eine erfolgreiche Anfrage und eine Team-Benachrichtigung aus.
- Eine Schließungsanfrage wird zuerst dauerhaft gespeichert; bei Speicherfehlern wird der vorherige Zustand wiederhergestellt und keine Team-Nachricht gesendet.
- Beim Ablehnen einer Schließungsanfrage wird ein fehlgeschlagener Speichervorgang ebenfalls zurückgerollt.
- Team- und Beschwerderollen bleiben getrennt; vertrauliche Beschwerden benachrichtigen nur die konfigurierte Beschwerderolle. Bestehende Rechte, Ticketdaten, Logs, Transkripte und Backups bleiben erhalten.
- Vier neue Regressionstests prüfen parallele Anfragen, Speicherfehler, Ablehnungs-Rollback und Berechtigungen.

**Betrieb:** Keine neuen Umgebungsvariablen, Datenmigrationen oder zusätzlichen Discord-Berechtigungen nötig. Dieses Repository enthält ausschließlich Quellcode; die signierte Produktionseinspielung erfolgt separat.
